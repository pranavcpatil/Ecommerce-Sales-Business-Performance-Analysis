# E-Commerce Sales & Business Performance Analysis

**An end-to-end Data Analytics project using Excel, SQL, Python, and Power BI.**

## Project Overview

This project analyses e-commerce sales data to understand business performance, product profitability, customer purchasing behaviour, sales trends, and product returns.

The goal is to transform raw business data into meaningful insights that can help a business make better decisions.

I completed the project using four analytical tools: Excel, MySQL, Python (Pandas), and Power BI.

## Tools & Technologies

| Tool            | Purpose                                                  |
| --------------- | -------------------------------------------------------- |
| Microsoft Excel | Data exploration, cleaning, PivotTables and analysis     |
| Power Query     | Data cleaning and transformation                         |
| MySQL           | Data querying, joins, aggregations and business analysis |
| Python          | Data analysis and cleaning using Pandas                  |
| Power BI        | Data modelling, DAX measures and interactive dashboards  |

## Dataset

The project uses five related datasets:

- **Customers:** Customer details, demographics, location and segments.
- **Products:** Product names and categories.
- **Orders:** Order dates, sales channels, payment methods and order status.
- **Order Items:** Product quantities, revenue, cost, discounts and profit.
- **Returns:** Return dates and return reasons.

The datasets contain 5,000 orders, approximately 1,000 customers and 200 products.

## Project Workflow

### 1. Excel & Power Query

- Explored the datasets and checked data quality.
- Handled missing values and inconsistent text.
- Standardised sales channels and payment methods.
- Used sorting, filtering and PivotTables.
- Analysed revenue, profit, orders and product performance.

### 2. SQL — MySQL

- Imported the project datasets into MySQL.
- Practised joins across multiple tables.
- Used GROUP BY, HAVING, subqueries and aggregate functions.
- Applied CASE WHEN, CTEs and window functions.
- Answered 15 business questions using SQL.

### 3. Python — Pandas

- Loaded datasets using Pandas.
- Explored and inspected data.
- Handled missing values and duplicates.
- Cleaned text columns and converted date columns.
- Created analytical summaries.
- Answered 15 business questions using Python.

### 4. Power BI

Created an interactive five-page dashboard using data modelling, DAX measures, charts, KPI cards, tables and slicers.

Dashboard pages:

1. **Overview:** Overall business performance, revenue trends, cities, customer segments and top products.
2. **Sales Analysis:** Monthly sales, payment methods, sales channels, order status and profit trends.
3. **Product Analysis:** Product revenue, category profitability, top products and product performance.
4. **Customer Analysis:** Customer segments, top customers, customer revenue and purchasing behaviour.
5. **Returns Analysis:** Return rate, return reasons, monthly return trends and returned revenue.

### Additional Findings

- Electronics generated the highest revenue among all product categories.
- Nexora Laptop 15-inch i7 16GB was the highest-revenue product, generating ₹15,128,138.20.
- Mobile App was the highest-revenue sales channel.
- Delivered orders accounted for 89.22% of all orders.
- There were 306 returned orders, representing a 6.12% return rate.
- Total returned revenue was approximately ₹6.21 million.
